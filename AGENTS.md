# Agent Instructions

Kodi script module wrapping `auth0-ciam-client` for addons. GitHub: `brianpatrickreavey/kodi.script.module.auth0-ciam-client`.

On a new machine:

```bash
git clone https://github.com/brianpatrickreavey/kodi.script.module.auth0-ciam-client.git
cd kodi.script.module.auth0-ciam-client
uv sync
```

Treat questions as read-only. `.github/copilot-instructions.md` still has the Angel Studios plugin header; prefer this file.

Distributed via the self-hosted repo `repository.kodi.reavey05.com`, not the official Kodi repo.

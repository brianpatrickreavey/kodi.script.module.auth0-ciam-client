Kodi script module wrapping `auth0-ciam-client` for addons. GitHub: `brianpatrickreavey/kodi.script.module.auth0-ciam-client`.

On a new machine:

```bash
git clone https://github.com/brianpatrickreavey/kodi.script.module.auth0-ciam-client.git
cd kodi.script.module.auth0-ciam-client
uv sync
```
